# Tiny BERT Vector Search Demo

This directory contains a small embedding demo for the TreeDB vector-search
work tracked in [issue #1510](https://github.com/snissn/gomap/issues/1510).

The demo uses `google/bert_uncased_L-2_H-128_A-2` to produce normalized
embeddings for a fixed set of short documents, then prints a cosine similarity
matrix and the most similar document pairs.

TreeDB should treat this as a demo/test harness around vector search, not as a
core storage dependency. TreeDB vector APIs should accept vectors generated by
callers.

## Run

```sh
python -m venv .venv
. .venv/bin/activate
pip install -r examples/vector_search/tiny_bert/requirements.txt
python examples/vector_search/tiny_bert/demo.py
```

The first run downloads the tiny BERT model from Hugging Face.
