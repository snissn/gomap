# Tiny BERT Vector Search Demo

This directory contains a small embedding demo for the TreeDB vector-search
work tracked in [issue #1510](https://github.com/snissn/gomap/issues/1510).

The demo uses `google/bert_uncased_L-2_H-128_A-2` to produce normalized
embeddings for a fixed set of short documents, then prints a cosine similarity
matrix and the most similar document pairs.

TreeDB should treat this as a demo/test harness around vector search, not as a
core storage dependency. TreeDB vector APIs should accept vectors generated by
callers.

The collection-side vector search implementation and smoke benchmarks live
under `TreeDB/collections`. The benchmark corpus is synthetic by default so it
can run without downloading this model, while this demo records the intended
caller-side embedding shape and normalization assumptions.

## Run

```sh
python -m venv .venv
. .venv/bin/activate
pip install -r examples/vector_search/tiny_bert/requirements.txt
python examples/vector_search/tiny_bert/demo.py
```

The first run downloads the tiny BERT model from Hugging Face.

To export the demo embeddings as a TreeDB benchmark fixture:

```sh
python examples/vector_search/tiny_bert/demo.py \
  --output-jsonl /tmp/tiny_bert_embeddings.jsonl
```

Run the TreeDB vector-search smoke benchmark:

```sh
TREEDB_VECTOR_BENCH_DOCS=1000 TREEDB_VECTOR_BENCH_DIMS=32 \
  go test ./TreeDB/collections -run '^$' \
  -bench 'BenchmarkCollectionVector(SearchExact|Index(Search|SearchInt8|FilteredSearch))$' \
  -benchtime=1x -count=1
```

Run the TreeDB vs USearch comparison benchmark with a local USearch bootstrap:

```sh
scripts/bench_vector_search_compare.sh
```

Run the optional tiny BERT fixture benchmark:

```sh
TREEDB_VECTOR_BENCH_JSONL=/tmp/tiny_bert_embeddings.jsonl \
  go test ./TreeDB/collections -run '^$' \
  -bench BenchmarkCollectionVectorTinyBERTFixture \
  -benchtime=10x -count=1
```

After installing the USearch C library and headers, run the same fixture against
the optional USearch Go baseline:

```sh
TREEDB_VECTOR_BENCH_JSONL=/tmp/tiny_bert_embeddings.jsonl \
  go test -tags usearch_bench ./TreeDB/collections -run '^$' \
  -bench BenchmarkCollectionVectorTinyBERTUSearchBaseline \
  -benchtime=10x -count=1
```
