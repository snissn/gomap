# Agent Runbooks

This directory contains agent-oriented implementation notes and runbooks.

These files are **not** normative contracts. When a runbook conflicts with a
contract or a canonical doc, the sources of truth are:

- `docs/contracts/*`
- `docs/TREEDB_WRITE_PATHS.md`
- `docs/TREEDB_STORAGE_FORMAT.md`

Runbooks:

- `docs/agents/BENCHPROF_MAINTENANCE.md`: benchmark profiling workflow and
  maintenance contract for `cmd/unified_bench` + `cmd/benchprof`.
- `docs/agents/TREEDB_VALUELOG_AUTOTUNE_RUNBOOK.md`: implementation notes for
  TreeDB value-log autotune work.
