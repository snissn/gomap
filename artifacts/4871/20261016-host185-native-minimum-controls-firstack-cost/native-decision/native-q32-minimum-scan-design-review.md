Ordinary/bounded/native births increment their actual counter before begin epoch and view load; completion increments epoch before decrement. Therefore an older unregistered acquisition either remains positive when its shard is examined or changes epoch before successful final equality. A complete acquisition between calls also changes epoch. An already registered old reader remains covered by original coherent registry minima. First cohort publication uses registry exclusion; joining an existing cohort cannot lower its seq.

Persisting the original short observation across yields is compatible with those rules. Implementation must admit/load each entry, preserve its next index, persist registry-to-terminal phase, and invalidate the whole accumulated attempt on nonzero counters or changed epoch. Merely saving indices while sampling epoch after initial scan is unsafe. Each later entry must validate E before consuming saved evidence, and every ready return must follow final admitted equality. The same rule applies when minimum is complete but caller phase4's following reservation refuses: a cached completed scalar is reusable only after newly admitted epoch equality; changed E restarts it. No unchecked permanently cached minimum and no ready minimum0 shortcut is acceptable.
