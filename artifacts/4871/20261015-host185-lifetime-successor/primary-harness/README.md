# Proposed hosted PRIMARY cost refresh

This is coordinator-owned preparation; no candidate source or hosted workflow has been changed yet.

The five existing hosted raw-path benchmarks omit the public PRIMARY replacement after a real DATA generation. The historical short guard used this exact committed `primary_generation_routing_v6_test.go` harness as a baseline-only Go overlay. This preparation preserves that 128-iteration workload and the original baseline behavior, records generation advances, runs the candidate public lifecycle/reopen control, and fixes eight alternating AB/BA pairs before execution. The timing limit is +5% median paired delta; median bytes and allocations must not grow. No profile is mixed with the timing run.

Both full source SHAs, the exact overlay bytes, both measured executables, toolchain/host information, every raw sample, command receipts and process snapshots are retained. CPU observations every 250ms retain seen processes even after they exit; a process entirely between observations can be missed, an explicit sampling limitation. A 2% unrelated-process CPU preflight is required. Interference over the measured interval makes the evidence nonqualifying. Missing, duplicated, malformed or reordered samples fail. There are no replacement samples, retries, threshold overrides or observation-only waiver.

Integration proposal: add one sequential step after the existing five-benchmark comparison in `treedb-tests.yml`, using the same resolved event base/head and toolchain. Write to a fresh `primary` child of the existing artifact directory so the existing unconditional upload retains both passing and failing evidence. Extend the gate's path filter and self-check list for the new script/tests. The five existing comparisons and thresholds remain unchanged. Independent exact-head review must cover this harness before its evidence is accepted. This bounded workload is an ordinary merge guard, not final graph or native qualification.
