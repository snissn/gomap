## Correct symbolic envelope

Use work vectors v=(records,bytes), checked componentwise sum ⊕ and componentwise maximum ∨. Define a **progress unit** as every reservation from a fresh public/Close invocation to the next persistent continuation advance, including all replayed entry/parent prefixes. The largest individual Reserve is insufficient. Some methods reserve a prefix on every retry and only advance after their nested child succeeds; fitting the child and prefix separately can still cause an endless false,nil loop.

For the fixed actual33 geometry theta and one explicitly bounded successor-writer schedule:

`G(theta) >= (F(theta) ⊕ C_fence(theta)) ∨ U_prepare(theta) ∨ U_finish(theta) ∨ U_close(theta)`.

`U_X = componentwise max { prefix(entry -> stable-state s) ⊕ local-required-unit(s) : reachable s in X }`.

For an atomic constructor admission, local-required-unit includes its complete effect-free preflight and concrete forward/rollback lease admissions, not merely its allocation Reserve. For an incremental loop, persisted indices/phases split its iterations; a loop with no persisted lookup cursor is one whole lookup unit. Include work through the first durable continuation update, not an arbitrary function boundary. A larger work vector is not permission to repeat a side effect after a yield. The expression remains unevaluated until all named variable geometry and prefix edges below are bound on the next exact source. Historical F367/871273 is not substituted.

## Concrete restart counterexample and correction

A source-ready parent can reserve its descriptor, call a child, receive false, and re-enter with the descriptor still needing admission. For example published phase7 reserves its detach descriptor before BindFinish; root phase8 reserves before Drop; Drop reserves before its non-resumable table lookup; arena queue reserves before owner accounting. Therefore `G >= each individual local reservation` is an invalid progress argument. Bound each complete prefix+next-advance path; do not remedy this by silently increasing a grant during Close. The added readiness bit must itself be included in the exact prefix and original cursor retained size.

1. **Actual target sizeof vector and current prices:** changed containing hash/clone headers, final readiness field, lease and callback types; checked authoritative F/remainder/caller expressions. Existing retained charges are not work-copy byte prices.
2. **Preparation geometry:** exact input/frame/payload maxima; clone allocated/abandoned lengths; changed/replaced source capture counts; all four table capacities/growth sizes; retired length; seal prefix debt. Existing source fields/observer rows cover many of these, but no single validated current unit envelope has been emitted.
3. **Owner admission envelopes:** SAME selected owner binding and active enrollment geometry for each atomic allocation before ready. A non-atomic earlier count is not a guarantee against a concurrent new enrollment; selected fixture must keep other producers absent during this stage or use the original locked admission refusal honestly. For the finite diagnostic there is no need for a global owner registry.
4. **Post-successor lookup envelope:** selected root/witness/queue lookups may encounter the original table with additional ordinary-writer entries. Bind L to actual bucket/probe geometry plus a source-derived bound for the one deliberately allowed CommitAt(34), or to a true existing admitted conservative capacity bound if available. Do not infer the bound from 33 history rows, previous observation, total retained bytes without a proven per-entry relationship, or a future successful run. If unavailable, this term remains unknown and G is not yet evaluable.
5. **Finish/Close capabilities and invariants:** genuine empty Set/manifest capacities and sharing, original seal/pager/token state, no user iterators/active reads on native captures, no unsupported WorkLease, stable index ownership through the bounded test schedule, genuine publisher and queue progress. Budgets fitting cannot repair a hard unsupported/lifetime invariant refusal. The selected backend route has no outputScope; do not silently admit the alternate unmetered scope route.

The smallest next observer/proof addition is a scalar selected-unit expression using these existing counts and authoritative price helpers, reporting separate `(local unit, replay prefix, combined progress vector, geometry-ready)` rows. It must only inspect original operands under their existing exclusions, use no constructor/admission to learn its cost, and return unavailable for unsupported or changing geometry. A local leaf high-water counter from a previous run is not a substitute for the summed-path proof. This is advice for the next coherent frozen packet, not a demand for general owner-graph traversal or arbitrary shared-work closure.

## Finite selected Close and nonclaims

For successful synchronous Close, every false,nil retry must either (a) have advanced a persisted finite phase/index/removal position or (b) be a budget refusal with a proved fresh-grant prefix+unit that fits G on the next attempt. Charge/alias transitions and first errors remain exactly original. Fixed source stack bounds, finite selected private arrays/frames/roots and one bounded ordinary successor give finite work only after the above geometry and concurrency conditions are established. Infinite new readers/enrollments/writers can prevent termination; the fixture must not generate them. Close must not be called while its own native Snapshot has an active read that this same thread can never release. Kernel I/O duration and ordinary DB teardown policies are separate from repo-owned work counters and retain their explicit process deadline.

`closeLockedV6` reuses its original frozen limits, resets consumed counters between retries and has no automatic no-progress detector; it can spin on a permanent fresh-unit mismatch. A process timeout can retain that failure but is not source proof of finite progress. Do not choose G from old367/871273, a round number, or a claimed total Finish scalar. No generic Finish bound, complete retained-union acceptance, Q32 fit, native publication or runtime grant is made here.
