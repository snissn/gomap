## PR37: optional journal/commitlog compression (metadata)

### Summary
- Add **optional zstd compression** for cached-mode journal/commitlog segments (metadata only).
  - Compression is **best-effort**: we only store compressed bytes when the compressed payload (plus a small header)
    is smaller than the raw payload (no size amplification).
  - Reader supports mixed streams: uncompressed segments + compressed segments in the same log.
- Plumb a new TreeDB option:
  - `Options.JournalCompression` (default: off)
- Add unified-bench flag:
  - `-treedb-journal-compress`

### Tests
```
go test ./TreeDB/internal/commitlog -count=1
go test ./... -count=1
```
