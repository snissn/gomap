## PR36: opt-in real-data harness for ValueLog dict tuning

### Summary
- Add a dev-only command to evaluate **ValueLog dict compression** behavior on a structured JSONL dataset:
  - sweep **dict history bytes** (`-dict-bytes`) and **group size K** (`-k`)
  - report payload ratio + total ratio + worst ratio + encode cost (ns/op)
- This is intended for **offline tuning** and does not change TreeDB runtime defaults.

### Usage
```
go run ./TreeDB/cmd/vlog_dict_realdata \
  -input tmp/treedb_kv_full.jsonl \
  -train 200000 -eval 50000 -cap 512 \
  -dict-bytes 16384,32768,40960 \
  -k 1,2,4,8,16,32 \
  -level fastest
```
