## Post-outcome negative-futility disposition

At 2026-09-21 20:37 UTC, the coordinator stopped serving/resource blocks 2–5
after the unchanged strict comparer confirmed block 1's failure. This uses
the issue's explicit decisive-rejection allowance and the owner's bounded
comparison/wall-time direction. It is a post-outcome disposition, not a
pretended prospective stopping rule: the immutable original plan only
explicitly named early construction/quality rejection and remains unchanged.

The all-50-pairs gate cannot pass once any required pair fails; all ten
observed treatment pairs fail its QPS threshold. Additional repetitions could
quantify timing variability and resource confidence, but cannot reverse that
conjunctive gate. The scoped mechanism assessment is also consistent across
both concurrencies: all 20 pack searches remain and navigation work barely
changes. This does not prove the optimizer can never help another workload.

Completed: two serving reports / 40 measured cells, ten treatment ratios and
one resource observation per arm / eight resource cells. Unmeasured: eight
remaining reports / 160 serving cells, forty treatment ratios and eight
resource observations / 32 resource cells. No full-five-external-block,
full-50-pair or resource-significance claim is made. All original failures
remain; no candidate setting, raw artifact, prospective plan or threshold
was rewritten. No new placement or local-search tuning loop follows.

The current algorithmic limit is that each physical pack is also an independent
navigation/search unit. Any next investigation into preserving one accepted
domain-level Vamana graph across bounded storage chunks changes that contract
and awaits an explicit scope decision. Such a probe would need to preserve
the graph's actual navigation edges and charge chunk residency, cross-chunk
work and potential cross-group rounds; merely sharing a frontier among four
already-independent graphs is not equivalent. It is not implemented or
qualified by this evidence packet.
